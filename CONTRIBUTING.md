Idiomatic or metaphorical function names are documented here.

### YOLO()

#### You Only Live Once

- Purpose: Executes a command with error checking temporarily disabled.  
- Usage: `YOLO some_command`  
- Behavior: Runs the command, records the exit status, restores error checking, and returns the status.  
- Notes: The name is idiomatic. It indicates execution without the usual safety net.
